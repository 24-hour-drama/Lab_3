# Лабораторная работа №3: «Циклы под микроскопом»: инварианты, вариант-функции, тотальная корректность

Приложение визуализирует формальное доказательство ***тотальной корректности*** циклических алгоритмов.

Для каждого цикла проверяются четыре условия: ***инициализация*** (`P ⇒ Inv`), ***сохранение*** (`{Inv ∧ B} S {Inv}`), ***выход*** (`Inv ∧ ¬B ⇒ Q`) и ***завершение*** (неотрицательная строго убывающая вариант-функция `t`). Математический аппарат слабейшего предусловия (`wp`) переиспользуется из ЛР-2 без дублирования кода.

Разработано на C# с использованием WPF (.NET 8).

---

## Возможности приложения

- Пошаговое ***Шаг*** и автоматическое ***Пуск*** исполнение циклов с полным контролем состояния.
- Цветовые индикаторы истинности инварианта ***до*** и ***после*** шага.
- Прогресс-бар убывания вариант-функции `t` — наглядное доказательство завершаемости.
- Автоматический разбор формулы сохранения `(Inv ∧ B) ⇒ wp(S, Inv)` через движок `Engine`.
- Генератор тестового массива показаний датчика с настройкой `n`, `min`, `max`, `T`.

---

## Как пользоваться

1. Выберите режим анализа в выпадающем списке.
2. Задайте параметры генератора (`n`, `min`, `max`, `T`) и нажмите ***«Сгенерировать»*** — в таблице появятся значения `a[i]`.
3. Управляйте исполнением:
   - ***Пуск*** - автоматический прогон цикла до завершения.
   - ***Шаг*** - одна итерация за нажатие (для отладки).
   - ***Сброс*** - возврат к исходному состоянию без «зависших» значений.
4. Внизу наблюдайте: текущий индекс `j`, результат `res`, убывание `t`.

---

## Встроенные пресеты

Три алгоритма анализа данных датчика, привязанные к задачам прошивки ночника:

| Пресет | Задача в прошивке | Инвариант |
| :--- | :--- | :--- |
| **PrefixSum** | Статистика энергопотребления: суммарная освещённость за ночь | `res = Σ a[i]`, `i ∈ [0..j-1]` |
| **CountGreaterThanT** | Подсчёт «дневных» интервалов (показания выше порога `T`) | `res = #{i \| a[i] > T, i ∈ [0..j-1]}` |
| **PrefixMax** | Калибровка пиковой яркости устройства | `res = max(a[0..j-1])` |

---

## Архитектура решения

- ***CycleAnalyzerService*** - инкапсулирует состояние цикла (массив, индекс `j`, накопленный `res`). Метод `Step()` выполняет итерацию.
- ***Engine (ЛР-2)*** - подключается внутри сервиса для вычисления `wp(S, Inv)`.
- ***UI-слой*** - бесшовно интегрирован в существующую экосистему «Умного ночника» (вкладки «Ночник» и «Конструктор фрагмента» сохранены).
